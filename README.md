# 高德 POI 数量预估・配额预警・多 Key 爬取工具

一个基于 **Python(Flask) + HTML/JS** 的本地 Web 工具。在浏览器里勾选「省 / 市 / 区县」和「POI 一级 / 二级分类」，即可：



1. **预估**勾选范围内的高德 POI 数量；

2. 计算**单个 API Key 单次 / 当日最多可获取的 POI 数量**；

3. 单组合超过上限时**自动分片**（二级分类展开 / 多边形网格）；

4. 单 Key 配额耗尽**自动轮询下一个 Key**；

5. 所需调用量超过全部 Key 免费配额时，**强制红色预警「可能限号」**（错误码 10003 / 10004 会被系统封停）。



***

## 快速开始

### 环境要求



* Python 3.9+（本机已验证 3.14 可用）

* 依赖：`flask`、`requests`（`requirements.txt` 已列出）

### 安装依赖



```
cd amap-poi-tool
pip install -r requirements.txt
```

### 启动



```
python app.py
```

浏览器打开 [http://127.0.0.1:8787](http://127.0.0.1:8787)

> Windows 也可直接双击根目录的 
>
> `start.bat`
>
> （会自动启动并打开浏览器）。

## 使用步骤



1. **第 1 步・选择行政范围**：左侧三列分别勾选省 / 市 / 区县（勾选省 = 勾选其下全部；支持搜索过滤、全选、清空）。

2. **第 2 步・选择 POI 分类**：勾选一级分类（20 大类），再在展开的二级分类里细选；也可在底部手动输入 typecode / 分类名（用 `|` 分隔）。

3. **第 3 步・添加 API Key**：

* 单个添加：粘贴 key + 备注；

* 批量导入：每行一个 key，可用 `|` 附加备注；

* 每个 key 可单独调整「日配额」「QPS」。

1. **第 4 步・配置参数**（默认即可）：

* 每次返回条数 `offset`（≤25，默认 20）

* 单组合翻页上限（官方默认 200，超限自动分片）

* 单 Key 日配额（个人认证「搜索类」约 5000 次 / 日，按控制台实际填写）

* 单 Key QPS（默认 3）

* 预估模式：全量逐组合（最准）/ 抽样估算

1. **执行**：

* **① 预估 POI 数量**：逐个组合调用真实接口读取 `count` 汇总，并输出配额报告（含超额 / 限号预警）。

* **② 开始爬取**：按 Key 轮询、自动分片、去重，SSE 实时显示进度，结果写入 `output/日期/poi_时间戳.csv`。

## 数据口径（来自高德官方文档）



| 项目      | 说明                                                   |
| ------- | ---------------------------------------------------- |
| 单次请求    | `offset / page_size` 建议 ≤ 25                         |
| 单组合翻页上限 | 官方「同请求参数翻页最多获取 **200** 条」，超过需分片                      |
| 免费配额    | 个人认证开发者「搜索服务」约 5000 次 / 月；搜索类日配额约 5000 次 / 日（以控制台为准） |
| 限号风险    | 错误码 `10003`（日访问超限）、`10004`（过于频繁）会被系统自动封停，次日自动解封      |
| 分片方式    | ① 二级分类展开；② 获取区县边界后用多边形网格自适应细分                        |
| 多 Key   | 单 Key 配额耗尽 / 被封自动轮询下一个；全部耗尽则暂停并等待                    |

> 各 Key 的免费配额请以 
>
> [高德开放平台控制台](https://console.amap.com)
>
>  实际显示为准，本工具提供默认值并允许逐个调整。

## 说明与边界



* **API Key 仅保存在内存中**（Flask 进程内），关闭后清空，不会写盘。

* 「预估」和「爬取」都会消耗真实的高德配额调用，请量力而行、按需选择范围。

* 批量全选全国 + 全部分类时组合数可达数千甚至上万，预估本身就会产生大量调用，此时请优先使用「抽样估算」或缩小范围。

* 工具仅用于合法合规的数据获取；请遵守高德开放平台服务协议，勿超配额滥用，否则可能被限号。
